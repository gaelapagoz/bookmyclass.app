Admin Journey

See how studio admins run
operations from one place

From secure access and scheduling to memberships, user management, learning content, and marketing — every studio operation runs from a single, organized control center.

Try the App ← Client Experience
Step 01

Secure admin access

The admin portal is protected by a dedicated, secure login. Role-based access ensures only authorized team members can reach studio controls, keeping operations safe and auditable.

  • Separate admin login from the client-facing experience
  • Role-based access for admins and instructors
  • Session security that keeps unauthorized users out
Step 02

Admin dashboard

A central dashboard gives studio admins a clear, at-a-glance view of upcoming classes, bookings, and key operational activity. The right information is surfaced immediately — no digging required.

  • Overview of upcoming classes and recent bookings
  • Quick access to the most common admin tasks
  • Organized layout that scales with your studio's activity
Step 03

Manage classes and schedules

Create, edit, and publish classes and recurring sessions from a structured schedule manager. Set capacity, assign instructors, configure timing, and manage pricing — all in a single workflow.

  • Create and edit classes with full detail control
  • Schedule recurring sessions and manage availability
  • Set per-class pricing, capacity, and instructor assignment
Step 04

Manage products, subscriptions, and entitlements

Configure memberships, class packs, and one-off products with flexible pricing. Entitlements define exactly what each plan unlocks for clients, giving full control over how access is structured.

  • Create and manage membership plans and class packs
  • Define entitlements that control class access per plan
  • Flexible pricing structures for different client segments
Step 05

Manage users and permissions

View and manage all client accounts, admin users, and instructors from a unified user panel. Update permissions, review booking history, and handle account actions without context-switching between tools.

  • Manage clients, admins, and instructors in one place
  • View individual booking history and membership status
  • Update roles, permissions, and account settings
Step 06

Manage learning content

Publish and organize online learning content for clients. Set up courses, modules, and structured learning paths to extend the studio's value beyond in-person classes and build a richer client relationship.

  • Create and publish online courses and modules
  • Organize content into structured learning paths
  • Control access by membership tier or entitlement
Step 07

Marketing, inbox, and support operations

Run targeted marketing campaigns, manage client communications, handle support, and maintain studio documents — all from the same admin workspace. Operations that used to require multiple tools are consolidated into one.

  • Create and send targeted marketing campaigns
  • Manage client inbox and support conversations
  • Maintain studio documents and operational records
