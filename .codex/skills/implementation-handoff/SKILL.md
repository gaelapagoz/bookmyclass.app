# Implementation Handoff

## Purpose
Produce a consistent completion report for implemented changes.

## Procedure
- Summarize what changed and why.
- List all changed files.
- List impacted services/modules.
- List test commands run and key outcomes.
- List residual risks, follow-ups, or deferred checks.

## Output Template
- `Change Summary`
- `Impacted Files`
- `Impacted Services/Modules`
- `Impacted Tests`
- `Residual Risks`
- `Documentation Conflicts Found`
